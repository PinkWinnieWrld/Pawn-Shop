# Pawn-Shop

A pawn shop script for QB-Core using:

- ox_lib
- ox_inventory
- ox_target
- okokBanking
- Randomized daily prices
- Police alerts for high-value sales

## Features
- Sell items with dynamic daily prices
- NPC pawn broker with ox_target
- Money deposited directly into okokBanking
- Police notified on suspicious high-value sales
- Fully configurable

## Installation
1. Drag the folder `pawnshop` into your server resources
2. Add to your server.cfg:


3. Make sure you have:
- ox_lib
- ox_inventory
- ox_target
- okokBanking
- qb-core

## Configuration
Edit `config.lua` to change:
- Pawn shop location
- Ped model
- Price ranges
- Police alert threshold
